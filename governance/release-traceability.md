# Release traceability control

One P0 security-control traceability record is present for the already-applied migration. It is not a product release or deployment.

A future release record must link an immutable commit SHA, bounded work items, decisions, reviewed migration references, validation evidence, artifact digest, target environment, reviewer state, rollback reference, and creation timestamp. A release is incomplete when any required link is missing, when evidence points only to mutable branch names, or when production values are embedded in the record.
